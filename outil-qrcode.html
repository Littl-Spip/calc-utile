Générateur de QR code

Crée un QR code à partir d'un texte ou d'une URL, prêt à télécharger.

Clique sur le QR code pour l'ouvrir en grand et le télécharger (clic droit → enregistrer).

QR code : ce qu'il faut savoir avant d'en imprimer un

Comment ça fonctionne

Un QR code stocke des données dans une matrice de carrés noirs et blancs. Il contient une redondance (correction d'erreur) qui permet de le lire même partiellement abîmé : de 7 à 30 % selon le niveau choisi. Plus le niveau de correction est élevé, plus le code est dense.

Un QR code statique contient directement l'URL : il ne peut pas être modifié après impression. Un QR code dynamique passe par un service intermédiaire, ce qui permet de changer la destination, mais dépend d'un tiers qui peut disparaître ou faire payer.

Réussir l'impression

Prévois une marge blanche (zone de silence) d'au moins quatre modules autour du code : sans elle, beaucoup de lecteurs échouent. Taille minimale : 2 cm pour un scan à 30 cm. Contraste maximal : noir sur blanc, jamais l'inverse, et évite les fonds colorés ou les logos au centre sans test.

Teste toujours le code imprimé avec deux téléphones différents avant un tirage.

Usages et limites

Un QR code pour un menu, une carte de visite, un wifi ou un paiement fonctionne bien. Un QR code collé sur un panneau publicitaire avec un lien long devient trop dense et illisible à distance. Et un QR code inconnu collé dans la rue est un vecteur d'arnaque : ne le scanne pas sans savoir où il mène.

Questions fréquentes

Combien de données peut contenir un QR code ?

Jusqu'à environ 3 000 caractères en version 40, mais un code aussi dense devient difficile à scanner. Reste sous 300 caractères pour un usage imprimé.

Le QR code expire-t-il ?

Un QR statique n'expire jamais. Un QR dynamique dépend du service : si l'abonnement s'arrête, le code cesse de fonctionner.
