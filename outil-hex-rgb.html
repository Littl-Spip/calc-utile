Couleurs hexadécimales et RGB : le même code, deux écritures

Décoder un code couleur

Un code hexadécimal comme #2F5BEA se lit en trois paires : 2F pour le rouge, 5B pour le vert, EA pour le bleu. Chaque paire va de 00 à FF, soit 0 à 255 en décimal. #2F5BEA correspond donc à rgb(47, 91, 234). Les codes à trois chiffres (#FFF) sont un raccourci : chaque chiffre est doublé, donc #FFF = #FFFFFF.

Le canal alpha (transparence) s'ajoute en quatrième paire, ou en quatrième valeur en rgba(). #2F5BEA80 est un bleu à 50 % d'opacité.

Choisir une couleur lisible

Le contraste entre le texte et le fond est la première cause d'illisibilité. Le standard WCAG demande un ratio d'au moins 4,5:1 pour du texte normal et 3:1 pour du grand texte. Un gris clair sur blanc (#999 sur #FFF) est à 2,8:1 : insuffisant pour du texte courant.

Pour foncer une couleur sans la salir, réduis la luminosité en HSV plutôt qu'en ajoutant du noir : le résultat reste saturé et cohérent avec la teinte d'origine.

Les pièges de la conversion

Les couleurs affichées dépendent de l'écran : un même code peut paraître différent sur un écran calibré et sur un téléphone en plein soleil. Et depuis les écrans larges gamut (Display P3), un code sRGB n'est pas interprété de la même façon partout. Pour une charte graphique, fixe tes codes en sRGB et vérifie-les sur au moins deux écrans.

Questions fréquentes

Combien de couleurs existe-t-il en hexadécimal ?

16 777 216 (256 × 256 × 256) en RGB 8 bits, sans compter la transparence.

Comment convertir un code hexadécimal en RGB ?

Sépare les paires, puis convertis chaque paire d'hexadécimal en décimal. FF = 255, 80 = 128, 00 = 0.
