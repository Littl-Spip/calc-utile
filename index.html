Questions fréquentes

Les calculs sont-ils fiables ?

Nos formules suivent les règles officielles (barème des impôts, formule d'amortissement bancaire, taux de cotisations). Les résultats restent des estimations indicatives — pour une décision importante, vérifie auprès d'un professionnel (banquier, notaire, expert-comptable).

Mes données sont-elles enregistrées ?

Non. Tous les calculs se font dans ton navigateur. Rien de ce que tu saisis n'est envoyé ni stocké ; seul le nombre de visites est compté, de façon anonyme. Les calculs que tu choisis de garder dans Mon espace restent sur ton appareil.

Est-ce vraiment gratuit ?

Oui. Le site est financé par de la publicité discrète. Il n'y a ni inscription obligatoire, ni version payante, ni fonctionnalité bloquée.

Puis-je utiliser les résultats dans un dossier ?

Oui pour un usage personnel. Ce sont des estimations : pour un dossier bancaire ou notarial, le document officiel (offre de prêt, devis, décompte) fait foi.

Un outil manque ?

Dis-nous lequel : les suggestions guident les prochains ajouts.
